# LSTM-Stock-Price-Prediction
A simplified LSTM implementation from scratch using NumPy for stock price prediction

Before running the code, install the Python libraries:

"pip install numpy pandas matplotlib yfinance"

If pip does not work, use:

"py -m pip install numpy pandas matplotlib yfinance"



After download, in the same file of the project's source code, open a terminal or PowerShell, run it as:

python "Term Project - LSTM Model.py"

or

py "Term Project - LSTM Model.py"
